feat: `elide: 'expand'` for the diff viewer - elided regions render as count rows with expand-up, expand-down, and expand-all `<button>`s (`data-expand`, the hidden `b` lines in `data-b-start` / `data-b-end`), revealing `DIFF_EXPAND_STEP` lines at a time (`expand_step`; an unchanged file offers both directions) and showing the lines in the `expanded` option (`DiffExpandedRange`s, `b` line numbers) as rows. `render_diff_segments` renders a diff in keyed pieces that join to the whole render, reusing a previous render's pieces so an expansion renders only what it reveals; `normalize_diff_expanded`, `clamp_diff_expanded`, `diff_expand_range`, and `diff_expand_line_range` are the range helpers. `CodeDiff` wires the controls by event delegation, renders each piece with its own `{@html}` so expanding leaves the other rows' DOM alone, takes `expanded` as an optional bindable prop (internal state unless bound; kept across model changes) and `expand_step`, and its `scroll_to_line` reveals a hidden line's surroundings before scrolling. `CodeDiff` now lexes `a` and `b` separately, so changing one or a view option doesn't re-lex the other. A source holding only some rows of an elided region renders each run of them, with a count row for the lines between, in every mode but `'omit'`. `theme_diff.css` styles the count row and its controls. The preprocessor leaves `elide="expand"` usages to runtime
