svelte_preprocess_fuz_code(options?: PreprocessFuzCodeOptions): PreprocessorGroup

Svelte preprocessor that compiles static Code and CodeDiff component content at build time, replacing runtime syntax styling and diffing with pre-rendered HTML.

A Code usage is static when its content is a string known at build time, or a ternary chain of them. A CodeDiff usage is static when a and b are such strings and every prop that shapes the rows (context_lines, elide, intraline, line_numbers, max_cost) is absent or a literal. Its split may be any expression: a dynamic one gets both views pre-rendered behind the expression, so toggling views stays static. Usages with spreads, a custom syntax_styler, or a non-static or unregistered lang are left to runtime, as are CodeDiff usages with a highlight or elide="expand", whose expand controls render rows from the component's diff.
